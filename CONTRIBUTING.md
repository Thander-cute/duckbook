# Contributing

Issues and pull requests are welcome. Duckbook is maintained by one person, so replies can be slow. Open an issue before building something larger, so we can agree on it first.

Follow [AGENTS.md](AGENTS.md): it has the rules for private data and saving, and the checks to run. Add a line to [CHANGELOG.md](CHANGELOG.md) for anything a user would notice.

By contributing you agree that your work is licensed under the same terms as Duckbook ([PolyForm Noncommercial 1.0.0](LICENSE)).
