# Changelog

Each version's section is its release notes: the build shows it in the app before an update, and the GitHub release uses the same text.

## 0.1.2 (2026-11-14)

- Week shows last week's unfinished plan as faint pencil lines: click one to keep it, or drop it with the ×, by crossing it out, or with Delete. A new week can copy the plan automatically (Settings › Planning).
- Date controls moved onto each page, next to its date; the top bar has the tabs and Settings only.
- Contacts: notes and DISC start blurred in grey until you open them, with a setting for each under Add-ons.
- Day photos: a short handwritten title on the strip, and a caption of up to four lines under the photo.
- Day notes: bold, italic and underline (Ctrl+B/I/U or Markdown-style typing), and a hand-drawn section line from `---`.
- If you sync between devices, update them all: an older version stops syncing, with an update message, once a 0.1.2 device has synced.

## 0.1.1 (2026-11-09)

- Contacts, an add-on page: name, gender, birthday and notes, laid out as an address book with an A–Z index. Birthdays show on the Month and Day pages.
- DISC colours for each person, an option under Contacts: pick a main and a second colour and drag the line between them to set the shares.
- Vietnamese holidays on the calendar, an add-on that works offline, including lunar dates such as Tết. Add your own yearly days from the Month page.
- Month words shrink to fit their square. Set the default size on the Month page; Ctrl+[ and Ctrl+] size one day.
- Windows app: choose the interface size in Settings. Ctrl with + or − no longer changes it, which fixes the app getting stuck at the wrong size.
- If you sync between devices, update them all: an older version stops syncing, with an error, once it receives Contacts or your own days.

## 0.1.0-beta.4 (2026-11-05)

- From the licence change on, Duckbook is licensed under PolyForm Noncommercial 1.0.0. Everything already published under MIT (releases and source) keeps the MIT licence. Third-party licences are unchanged.
- App updates show the new version's notes and a progress bar, explain failures plainly with Try again, and are checked again every few hours while Duckbook is open.

## 0.1.0-beta.3 (2026-11-05)

- The Windows app checks GitHub releases for a new version and installs it when you choose, after saving every page.
- Open source under the MIT licence; the app ships third-party licence notices.

## 0.1.0-beta.2 (2026-11-03, not published)

- Google Drive sync in the Windows app, as in the browser version.
- A save that arrives after the page changed elsewhere is merged instead of refused.

## 0.1.0-beta.1 (2026-10-25)

- First Windows beta: month, week, day and reflection pages, Focus Map, day photos, PIN lock, verified local backups, and JSON export and import.
