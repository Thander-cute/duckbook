# Duckbook 0.1.0-beta.3

Windows desktop build that can update itself.

## What's new

- Duckbook now checks for a new version when it opens, and when you press Check now in Settings → Data → App updates.
- When a new version is out, a note at the top says so. You choose when to download it, and when to install.
- Install and restart saves every page first. If something isn't saved, it doesn't install. Your notebook and settings stay as they are.

## Updating from beta.1 or beta.2

Those versions can't update themselves. Install this one by hand, once:

1. Let edits finish saving, then close Duckbook.
2. Keep a copy of `%APPDATA%\duckbook\notebook`, as for any beta.
3. Run `Duckbook-Setup-0.1.0-beta.3.exe`.

From then on, Duckbook offers each new version itself.

## How updates work

- Duckbook asks GitHub for the newest release of `Thander-cute/duckbook`: when it opens, and when you press Check now. GitHub sees your IP address and the app's request, like any download. Nothing about your notebook is sent.
- Nothing downloads or installs until you press the button for it. The download is checked against the size and SHA-512 listed in the release before it runs.
- The installer is not code-signed, so Windows SmartScreen may warn on a first manual install.
