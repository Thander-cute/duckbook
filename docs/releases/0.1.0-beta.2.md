# Duckbook 0.1.0-beta.2

Windows build that brings the desktop app up to the browser version. Not published as a release.

## What's new since 0.1.0-beta.1

- **Google Drive sync** in Settings → Data → Sync with Google Drive. Press Connect and sign in with Google in your browser. The app's own OAuth client is built in, and it uses only the `drive.file` permission. Pages and day photos go into a "Duckbook Sync" folder in your Drive. That folder is not encrypted. See `docs/DATA-AND-PRIVACY.md`.
- A save that arrives after the page changed elsewhere (another tab, or another device through sync) is merged, not refused. Text typed on both sides is kept.
- Settings → Data links to the public privacy policy and terms (`https://duckbook.khoadev.id.vn`). These open in the system browser.
- Everything else from beta.1 is unchanged (Focus note text now fits square notes; ideas are capped at 100 characters).

## Updating from beta.1

1. Let edits finish saving, then close Duckbook (the beta.1 window).
2. Run `release\Duckbook Setup 0.1.0-beta.2.exe`, or run `release\win-unpacked\Duckbook.exe` directly.
3. The desktop notebook stays in `%APPDATA%\duckbook\notebook`. The first time it opens, beta.2 adds its sync records to the notebook; pages are not changed. Keep an independent copy of that folder first, as for any beta.

The browser version (`Duckbook.cmd`) has its own notebook. If you use both, connect each of them to the same Google account and they sync through Drive.

## Known limitations

- The installer is unsigned (SmartScreen warns). There is no auto-update.
- Sync is not encrypted yet. Drive files are not compacted (one small file per batch of saves).
- The desktop close-flush test step is still flaky: after a relaunch the test window can lack focus, so its typed text never reaches the page. This is a test issue, not lost saves (checked 2026-11-03).
