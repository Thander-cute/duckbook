# Duckbook 0.1.0-beta.4

Clearer app updates for the Windows app.

## What's new

- Settings → Data → App updates shows what's new in the next version, and a progress bar while it downloads.
- If a check or download fails, Duckbook says why in plain words (no connection, nothing found, or a download that didn't match its checksum and was thrown away) and offers Try again.
- While Duckbook stays open, it looks for a new version again every few hours.
- The note at the top says when an update is downloaded and ready to install.

## Updating

From 0.1.0-beta.3: Duckbook offers this version itself. Press Download, then Install and restart. It saves every page first and won't install if anything is unsaved.

From 0.1.0-beta.1 or beta.2: those versions can't update themselves. Install this one by hand, once:

1. Let edits finish saving, then close Duckbook.
2. Keep a copy of `%APPDATA%\duckbook\notebook`, as for any beta.
3. Run `Duckbook-Setup-0.1.0-beta.4.exe`.

## How updates work

- Duckbook asks GitHub for the newest release of `Thander-cute/duckbook` when it opens, every few hours while it stays open, and when you press Check now. GitHub sees your IP address and the app's request, like any download. Nothing about your notebook is sent.
- Nothing downloads or installs until you press the button for it. The download is checked against the size and SHA-512 listed in the release before it runs.
- The installer starts after Duckbook has closed. If it fails at that point, the old version stays installed; open Duckbook again and retry, or install by hand.
- The installer is not code-signed, so Windows SmartScreen may warn on a manual install.
