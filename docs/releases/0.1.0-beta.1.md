# Duckbook 0.1.0-beta.1

Private Windows beta of the local notebook. Includes Month, Week, Day, Reflect,
Focus Map, day photos, the focus timer, paper settings, the optional PIN lock,
local backups and the Electron desktop shell. Archive, Google Calendar, Android
and cloud sync were not part of this beta.

## Downloads and use

- `Duckbook-Setup-0.1.0-beta.1.exe`: per-user Windows x64 installer, no Node install required.
- `Duckbook-0.1.0-beta.1-win-x64.zip`: unpack and run `Duckbook.exe`; keep all files together.
- `SHA256SUMS.txt`: checksums for both downloads.
- Local browser use remains available from the source: install Node.js 24+, then run `Duckbook.cmd`.

The installer is unsigned. Windows may display a publisher/SmartScreen warning.
Installer execution on a clean Windows machine has not been verified.

## Existing notebooks and updates

Wait for pending saves and close Duckbook before replacing or installing binaries.
Existing data stays outside the application directory. This beta does not change
the notebook schema or automatically move a notebook.

- Local browser notebook: `%LOCALAPPDATA%\Duckbook`.
- Electron notebook: `%APPDATA%\duckbook\notebook`.
- These are separate notebooks, with no automatic sync. Bringing browser pages
  into Electron is an explicit action in Settings and requires stopping the
  browser server first.
- For browser updates, reopen `Duckbook.cmd`, accept the server restart if offered,
  then reload the browser tab.

Before beta use, keep an independent copy of the whole notebook directory,
including photos, after closing the app/stopping its server. Same-disk backups
do not protect against disk loss. The PIN is an access lock, not encryption.

## Known limitations

- JSON exports contain photo references, not photo files. Retain the `photos`
  directory when transferring or backing up a notebook.
- A code review identified legacy recovery edge cases, not yet reproduced in
  release tests: restoring a pre-API-level-2 backup can report a mismatch after
  replacing pages; JSON round trips may lose or duplicate set-aside unknown
  values; photo cleanup does not account for references found only in set-aside
  values. Keep original imports and independent backups, and avoid relying on
  this beta to recover malformed/newer-format or very old notebooks.
- Pre-import and pre-restore backups share a retention pool of 20. Documentation
  elsewhere may describe older retention rules; do not rely on an early import
  backup being retained forever.
- Timer audio, Vietnamese IME and true full screen inside Electron have not been
  manually verified. Automated desktop checks do not prove these interactions.
- There is no automatic updater, encryption, cloud sync, Android app or Calendar
  integration in this beta.
